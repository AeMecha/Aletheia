Aletheia 0.2.1 fixes ordinary library inventory questions on Windows and Ubuntu/Debian x64.

- "Do I have anything in the library?" and "Can you check if I have anything in the collection?" now return the actual archive count and saved titles with source links.
- Empty-library checks, conversational phrasing and collection synonyms use the complete index without requiring a generation model.
- Questions about a particular topic or date continue through document search.
- Regression checks cover empty/populated archives and newly added Markdown files.

Install the Windows `.exe`, or use `sudo apt install ./Aletheia-0.2.1-linux-amd64.deb` on Ubuntu 24.04+/Debian 12+ amd64 with a desktop environment and SSE4.2-capable CPU. The Windows installer is unsigned. This patch retains the existing native dependency and CPU requirements. Large generation-model weights are downloaded separately or selected locally; configured model/API connections and user profiles remain in their existing data directories.

The release includes Windows setup, the Debian package, the corresponding tagged source archive and SHA-256 checksums. Native release builds run the test suite and verify the packaged applications before publication.
