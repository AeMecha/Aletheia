Standalone Aletheia for Windows and Ubuntu/Debian x64, using `qwen3.8-9b-hermes-fc-tooluse` with a built-in inference engine. LM Studio is an optional connection.

## Downloads

- **Windows:** `Aletheia-Setup-0.1.2.exe`. Close a running older version before installing. The installer is unsigned.
- **Ubuntu 24.04+ / Debian 12+, amd64:** `Aletheia-0.1.2-linux-amd64.deb`. Install with `sudo apt install ./Aletheia-0.1.2-linux-amd64.deb`, then launch Aletheia from the applications menu.
- **Corresponding source:** `Aletheia-Source-0.1.2.zip`, licensed AGPL-3.0-only with dependency notices.
- **Checksums:** `SHA256SUMS.txt` contains SHA-256 hashes for these three downloads.

The app bundles its CPU/GPU engines and offline search model. On first launch, select your existing `qwen3.8-9b-hermes-fc-tooluse.Q4_K_S.gguf` or download it in the app (5.5 GB). Qwen weights are obtained separately. Existing archive data and settings are preserved by updates.

## Changes

- Archive overview answers collection-wide questions using actual document counts, metadata types/topics and real titles with source links. It also works before AI setup.
- Clearer guidance when topical search finds no matching passage.
- Explanatory code comments and an architecture guide.
- Ubuntu/Debian packaging with native inference/search libraries, desktop integration and Chromium sandbox setup.

Document title editing, persistent light/dark mode, and repaired document preparation from 0.1.1 are included.

## Validation

Release builds run the regression suite and verify the packaged archive/renderer bridge on Windows and Ubuntu. The Linux job also installs and inspects the Debian package and starts the bundled CPU engine. These automated checks use synthetic records without downloading the large Qwen weights; full Qwen generation on Linux remains outside their coverage. The Windows Qwen engine was also tested locally against the exact model.
