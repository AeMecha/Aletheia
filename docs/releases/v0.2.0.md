Aletheia 0.2.0 adds configurable AI models for Windows and Ubuntu/Debian x64.

- **Local models:** choose a llama.cpp-compatible instruction/chat GGUF with an embedded chat template. Files no longer have to match the default Qwen download.
- **API connections:** configure a Chat Completions base URL, model ID and optional key. LM Studio and Ollama presets are included, alongside custom local/hosted endpoints. Fetch models or enter an ID manually.
- **Compatibility:** automatic schema/JSON/prompt negotiation, selectable API output-token parameter and context sizes up to 262,144 tokens. Models must support the context selected and reliably follow the JSON instructions. All modes retain answer, source and document validation.
- **Default model:** the verified, resumable Qwen download remains available. Existing files, archive data, themes and LM Studio preferences are preserved when updating.

Local GGUF support depends on the bundled llama.cpp engine, the model's chat template and available memory. APIs using only a different native protocol need a Chat Completions-compatible endpoint or gateway. No paid external API was used for verification.

Install the Windows `.exe`, or use `sudo apt install ./Aletheia-0.2.0-linux-amd64.deb` on Ubuntu 24.04+/Debian 12+ amd64 with a desktop environment and SSE4.2-capable CPU. This release does not change legacy CPU support. The installer is unsigned; large model weights are not bundled. Local search remains on the computer; an API receives the current input and retrieved passages.
