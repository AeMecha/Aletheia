# Contributing to Aletheia Scriptorium

Use a feature branch, describe the behavior changed, and run the existing tests before submitting changes. Keep user profiles, credentials, model weights and generated packages out of source control.

## Provenance and notices

Read LICENSING.md, ATTRIBUTION.md and the original custom license in LICENSES/ before changing upstream-covered material.
